# Código de Conducta de VinoPorMi

## Nuestro Compromiso

Para hacer que el proyecto VinoPorMi sea un entorno abierto y acogedor, nos comprometemos a respetar a todas las personas que participan en el proyecto, sin importar su nivel de experiencia, género, orientación sexual, discapacidad, etnia, religión, edad o nacionalidad.

## Nuestros Estándares

Comportamientos que contribuyen a crear un ambiente positivo:

- **Respeto y amabilidad**: Tratar a los demás con respeto, empatía y consideración
- **Comunicación inclusiva**: Usar lenguaje inclusivo y evitar términos que puedan ser ofensivos
- **Colaboración constructiva**: Trabajar juntos para resolver problemas y mejorar el proyecto
- **Mentoría y apoyo**: Ayudar a otros miembros de la comunidad a crecer y aprender
- **Paciencia y comprensión**: Recordar que todos tenemos diferentes niveles de experiencia y conocimiento
- **Escucha activa**: Considerar diferentes perspectivas y estar abierto a nuevas ideas
- **Responsabilidad**: Asumir la responsabilidad de nuestros errores y aprender de ellos

Comportamientos inaceptables:

- **Acoso o intimidación**: Comentarios o acciones que creen un ambiente hostil
- **Discriminación**: Comentarios basados en género, orientación sexual, raza, religión, etc.
- **Lenguaje ofensivo**: Insultos, groserías o lenguaje inapropiado
- **Spam o contenido irrelevante**: Publicaciones que no aportan valor a la discusión
- **Divulgación de información privada**: Compartir información personal de otros sin consentimiento
- **Comportamiento disruptivo**: Acciones que interfieren con el progreso constructivo del proyecto

## Aplicación

Proyectos de VinoPorMi:

- Repositorios de código
- Issues y Pull Requests
- Discusiones y comentarios
- Eventos y meetups del proyecto
- Canales de comunicación oficial

Responsabilidades:

- **Maintainers**: Monitorear y hacer cumplir este código de conducta
- **Contribuidores**: Seguir estas pautas en todas las interacciones
- **Usuarios**: Reportar comportamientos inapropiados a los maintainers

## Reporte de Incidentes

Si presencias o experimentas un comportamiento que viole este código de conducta:

### Contacto para Reportes

- **Email de contacto**: [elulice@outlook.com]
- **Issues privados**: Crea un issue en GitHub con la etiqueta `conduct`
- **Contacto directo**: Reach out a cualquiera de los maintainers del proyecto

### Información a Incluir

- **Descripción detallada**: Qué ocurrió, cuándo y dónde
- **Personas involucradas**: Quiénes participaron
- **Testigos**: Quiénes presenciaron el incidente
- **Evidencia**: Capturas de pantalla, enlaces, etc.
- **Impacto**: Cómo te afectó la situación

### Proceso de Reporte

1. **Recepción**: Recibimos y acknowledge tu reporte dentro de 24-48 horas
2. **Evaluación**: Investigamos la situación de manera confidencial
3. **Acción**: Tomamos las medidas apropiadas según la gravedad
4. **Seguimiento**: Te informamos sobre las acciones tomadas

## Consecuencias

Las consecuencias por violar este código de conducta pueden incluir:

- **Advertencia verbal o escrita**
- **Remoción temporal del proyecto**
- **Remoción permanente del proyecto**
- **Bloqueo de acceso a repositorios y recursos**
- **Reporte a autoridades** (en casos graves)

Las consecuencias dependerán de:

- **Gravedad** de la violación
- **Historial** de comportamiento previo
- **Impacto** en la comunidad
- **Intención** detrás del comportamiento

## Mejora Continua

Este código de conducta es un documento vivo:

- **Revisiones regulares**: Revisamos y actualizamos este documento cada 6 meses
- **Feedback comunitario**: Agradecemos sugerencias para mejorarlo
- **Transparencia**: Publicamos cambios y razones detrás de ellos

## Alcance

Este código de conducta aplica a:

- **Espacios del proyecto**: Repositorios, issues, PRs, discusiones
- **Eventos del proyecto**: Meetups, conferencias, workshops
- **Comunicaciones**: Emails, chats, videollamadas relacionadas con el proyecto
- **Representación del proyecto**: Cuando actúas en nombre de VinoPorMi

## Exenciones

Este código de conducta NO aplica a:

- **Interacciones personales fuera del proyecto**
- **Otros proyectos o comunidades**
- **Contenido en tus repositorios personales**
- **Opiniones políticas o religiosas personales** (siempre que no discriminatorias)

## Filosofía

Nuestra filosofía se basa en:

- **Inclusión**: Queremos que todos se sientan bienvenidos
- **Seguridad psicológica**: Crear un espacio donde sea seguro expresar ideas
- **Crecimiento**: Aprender juntos como comunidad
- **Excelencia técnica**: Fomentar la colaboración para mejorar el proyecto
